## अवलोकन

OrcaRouter Lite एक self-hosted LLM राउटर है जो OpenAI-compatible API, BYOK, streaming, और `model="auto"` के जरिए सबसे किफायती सक्षम मॉडल का स्वचालित रूटिंग देता है।
