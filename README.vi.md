## Tổng quan

OrcaRouter Lite là bộ định tuyến LLM tự lưu trữ, tương thích API OpenAI, hỗ trợ BYOK, streaming và tự động chọn mô hình rẻ nhất đáp ứng yêu cầu bằng `model="auto"`.
